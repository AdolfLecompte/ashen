## Install

```sh
bash -c "$(curl -fsSL https://raw.githubusercontent.com/AdolfLecompte/ashen/main/install/boot.sh)"
```

Arch (and Arch-based distros) with Hyprland. It asks three questions, installs, and asks you to reboot.

## Update

```sh
ashen update
```

Coming from 3.5.0 or older? Run the install line above once instead: in those versions the Update button only reinstalls.
